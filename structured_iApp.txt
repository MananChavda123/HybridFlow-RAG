TITLE:
Card Format

NARRATIVETEXT:
It is a format into which a card is defined by the data pattern compatible with the SPECTRA Controller. Below are the parameters of the ‘card format’.

TITLE:
Reader Interface

NARRATIVETEXT:
Reader Interface is mandatory to select and must be according to the requirements of RFID Reader connected to the Controller. It would be either a Clock Data or a Wiegand

TITLE:
Clock

NARRATIVETEXT:
: SPECTRA default interface of reading 26 bit card.

TITLE:
Wiegand

TITLE:
: Standard interact recognition word wide.

NARRATIVETEXT:
The original Wiegand format has one parity bit, facility code of 8 bits, ID code of 16 bits, and a trailing parity bit for a total of 26 bits. The first parity bit is calculated from the first 12 bits of the code and the trailing parity bit from the last 12 bits. However, inconsistent implementations and extensions to the basic format may exist.

TITLE:
Site Code

NARRATIVETEXT:
This option will be available when you have selected the reader type as "Wiegand" and the Wiegand bits are "26".This should not be changed after a successful installation, as the controller and application would malfunction. This is only a one-time setting done into the controller.

TITLE:
Card Format

NARRATIVETEXT:
Two type of card format is supported i.e. Decimal and Hex

TITLE:
Wiegand Bits

NARRATIVETEXT:
It will configure the Wiegand Bits on a Controller or a reader. The Start bit can be set through "Number of Start bits" parameter

TITLE:
Site Code

NARRATIVETEXT:
It sets the site code length and unlike Spectra Format its Range could be customized. This is a one-time setting. Its range can be set via use of the Starting and End Bits of a Site code

TITLE:
Card Number

NARRATIVETEXT:
It configures the Range of Card Number. The start bit can be set through the use of the "Start bits and End Bits"

TITLE:
Stop Bits

NARRATIVETEXT:
Provide the end digits up to which the card bits can be configured

TITLE:
Reader type

NARRATIVETEXT:
Depends upon the RFID Reader connected to the Controller to avoid a malfunction. Available reader types are EMReader, HID Reader, HID IClasss, Mifare Reverse, Mifare Forward, etc.
